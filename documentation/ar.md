# درجة Rockall

[الشروط والمصادر والأذونات](https://elucenia.org/ar/tools/escore-de-rockall)

## كيفية الاستخدام

استخدم الأداة في البوابة أو افتح index.html عبر خادم HTTP محلي. اختر اللغة، وأكمل الحقول، ثم أجرِ الحساب.

## المدخلات والوحدات

### العمر

`idade`

- `0` — \< ٦٠ سنوات
- `1` — ٦٠ إلى ٧٩ سنوات
- `2` — ≥ ٨٠ سنوات

### صدمة

`choque`

- `0` — دون صدمة (الضغط الانقباضي ≥ ١٠٠ ومعدّل القلب \< ١٠٠)
- `1` — تسرّع القلب (الضغط الانقباضي ≥ ١٠٠ ومعدّل القلب ≥ ١٠٠)
- `2` — انخفاض الضغط (الضغط الانقباضي \< ١٠٠ mmHg)

### الأمراض المصاحبة

`comorb`

- `0` — لا شيء مهمّ
- `2` — قصور القلب أو مرض القلب الإقفاري أو مرض مرافق مهمّ آخر
- `3` — قصور كلوي أو قصور كبدي أو سرطان منتشر

### التشخيص بالتنظير

`diag`

- `0` — Mallory-Weiss أو لا آفة (دون علامات نزف)
- `1` — جميع التشخيصات الأخرى
- `2` — ورم في السبيل الهضمي العلوي
- `na` — لم يُجرَ التنظير بعد

### علامات نزف حديث

`estigma`

- `0` — لا شيء أو بقعة داكنة فقط (هيماتين)
- `2` — دم في السبيل العلوي أو خثرة ملتصقة أو وعاء ظاهر أو نزف نافوري
- `na` — لم يُجرَ التنظير بعد

## إصدار الطريقة

Rockall 1996: قبل التنظير 0–7 والكامل 0–11؛ دون خلط مع GBS

## المعادلة الموثقة

قبل التنظير (0 إلى 7): العمر (0 إلى 2) + الصدمة (0 إلى 2) + الأمراض المرافقة (0 أو 2 أو 3).

الكامل (0 إلى 11): يضيف التشخيص (0 إلى 2) وعلامات النزف الحديث (0 أو 2).

## الحدود والفئة السكانية

دُرست Rockall لعام 1996 لدى أشخاص أكبر من 16 سنة لديهم نزف حاد في الجهاز الهضمي العلوي. تعتمد النسخة الكاملة على التشخيص وعلامات النزف بالتنظير؛ ولا تتضمن نسخة ما قبل التنظير هذه المعلومات. يساعد التصنيف في النظر في التدبير، لكنه لا يحدد أمان الخروج الفردي أو غياب إعادة النزف.
